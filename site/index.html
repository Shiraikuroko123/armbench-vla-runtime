ArmBench

让动作块在抵达控制器前，先通过时间检验。 Make action chunks answer for time.

面向 Physical Intelligence 的 π0.5（pi-zero-point-five）VLA 与七自由度 Panda 验证基座，研究推理延迟如何让动作过期，以及运行时如何选择可执行后缀、拒绝坏响应并保存可审计证据。 A runtime and evaluation platform for Physical Intelligence's π0.5 VLA and a seven-DoF Panda validation base, studying how inference delay makes actions stale and how a supervisor can select, reject, and audit what reaches control.

RUNTIME QUESTION

模型输出是新的，动作却可能已经旧了。 The response is new. Its first actions may not be.

Action-chunk 策略用一次观测预测未来多步动作。推理期间控制时钟继续前进；如果仍从索引 0 开始执行，控制器会重放属于过去时刻的动作。 An action-chunk policy predicts multiple future controls from one observation. The control clock keeps moving during inference; starting at index zero can replay commands intended for time that has already elapsed.
